flyt

FetchLight for YouTube.

A lightweight, native macOS app for downloading YouTube videos. Paste a link, pick a format, download.

Download for Mac

Requires macOS 14.6 or later

What it does

  • Downloads at the resolution, container and audio track you choose, or audio only.
  • Trims to one or more sections of a video by timestamp.
  • Saves subtitles alongside the video or embedded in it.
  • Runs several downloads at once and keeps a history of them.
  • Keeps its own copy of yt-dlp up to date, so it keeps working as YouTube changes.

Opening it the first time

flyt isn't notarized, so macOS blocks it the first time you open it. To allow it:

  1. Try to open flyt. A dialog says it can't be opened.
  2. Open System Settings → Privacy & Security.
  3. In the Security section, click Open Anyway next to the message about flyt.
  4. Confirm in the dialog that appears.

You only need to do this once.
